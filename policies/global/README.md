# Global Policies

Reserved for policy content that genuinely applies across every project using
the hub (e.g. "never commit secrets", "destructive actions require
confirmation"). Empty in v1 — no global policy has been written yet that isn't
already covered by a skill's own Safety Contract.

Do not put project-specific rules here — see `policies/projects/` and
[docs/DESIGN.md](../../docs/DESIGN.md) for the precedence order.
