# Project Policies

Project-specific rules live here, one subdirectory per project, e.g.
`policies/projects/final-check/`, `policies/projects/one-rope/`,
`policies/projects/decode/`. Nothing has been migrated into this directory in
v1 — the source projects' frozen state (Gold SHA, Validator SHA, R19,
BLOCKER/REVIEW criteria, benchmark thresholds, Sector 05 locks, gameplay
constants, Coach Copilot MVP locks, GO/STOP thresholds, etc.) stays in those
projects' own repositories and must never be promoted into a global skill.

Project Policy outranks Domain Skill and Global Skill — see the precedence
order in [docs/DESIGN.md](../../docs/DESIGN.md).
