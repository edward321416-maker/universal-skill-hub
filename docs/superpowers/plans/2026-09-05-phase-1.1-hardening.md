# Phase 1.1 Hardening — Implementation Plan

Date: 2026-09-05
Branch: `phase-1.1-hardening`
Precondition: local shell (Bash/PowerShell) access was blocked for this
session by a broken global `PreToolUse` hook pointing at a deleted project's
absolute checkout path; that was repaired first (see
`docs/DESIGN.md`'s "Phase 1.1: hook-safety invariant" section) and shell
recovery was verified with a fresh smoke test before any hub work resumed.

## Scope

Harden Phase 1's mechanisms rather than migrate a new skill:

- **Eligibility**: L3 explicit-intent/permission gates, EXPERIMENTAL-L3-
  never-auto, L4-requires-informed-confirmation (not just no-auto),
  forbidden-capability-actually-used enforcement, declared-conflict
  enforcement, Project Policy override. Done — 10 new RED-then-GREEN tests
  in `scripts/__tests__/eligibility.test.mjs`.
- **`requires_not` -> `forbidden_capabilities`**: renamed in
  `registry/compatibility.json` with a backward-compatible reader
  (`scripts/load-compatibility.mjs`). Done.
- **Drift detection**: replaced marker-hash-only comparison with a full
  re-render-and-byte-compare, after a regression test proved the old
  approach missed a hand-edited adapter body left under an untouched
  marker. Done.
- **Agent Skills naming/description validation hardened** with a real YAML
  parser (`js-yaml`, pinned exact version, 0 known vulnerabilities at time
  of pinning) replacing the Phase 1 hand-rolled line parser, plus name
  length (<=64), consecutive-hyphen, and description length (<=1024)
  checks. Done — 6 new RED-then-GREEN tests.
- **Registry <-> canonical consistency**: `scripts/registry-consistency.mjs`,
  with field ownership documented in `docs/DESIGN.md`. Done.
- **User-level distribution**: `scripts/install-skills.mjs`, dry-run by
  default, managed/unmanaged classification, refuses to overwrite unmanaged
  files, refuses to combine a project checkout path with a user-scope
  install. Done for Claude Code/Codex/Cursor/OpenCode (filesystem-adapter
  platforms); Codex's specific user-level path is an unverified assumption
  (documented in `docs/DESIGN.md`).
- **Hook-safety invariant**: `scripts/hook-safety.mjs` plus a regression
  test built from the actual incident. Done.
- **CI**: `.github/workflows/ci.yml` — install, unit tests, validate,
  registry-consistency, render-adapters + `git diff --exit-code`,
  check-drift, installer dry-run smoke test. `npm run verify` mirrors this
  locally.

## Explicitly not done in this PR

- ChatGPT / claude.ai Projects bundle/export generator — not implemented.
  No upload/publish automation of any kind; that stays a manual step
  outside this repo by design.
- No numeric routing precision/recall/false-invocation-rate measurement.
- Project-policy fixtures for FINAL CHECK / ONE ROPE / DECODE /
  green-remodeling-map were exercised only as a generic
  `projectPolicy.blockedSkillIds` mechanism in unit tests — no actual
  cross-project fixture data was pulled from those repositories in this
  PR; that would be follow-up work reading those repos' real policy
  documents (read-only) rather than fabricating example policy content
  here.
- No merge. This branch and its PR are for independent review.
